## Expenses and categories

Every expense has an amount, a date, a category and an optional description.

![The Expenses page with the period and category filters](/guide/expenses.png)

**Add an expense** with the **+** button, from any page. Fill in the amount (like 12.50), the date, the category and a description, then save.

**Find expenses** on the Expenses page. Switch between **All** and **This month**, and filter by category. The list shows 25 expenses per page. Expenses that a subscription created carry a repeat icon.

**Edit or delete** an expense with the pencil or trash icon on its row. Deleting asks you to confirm.

**Categories** live on the Categories page, each with a name, an optional icon and a color. Categories marked **system** come with the app for everyone; you can't edit or delete them. You can add your own, and edit or delete them. If you delete a category that still has expenses, GastApp asks which category to move them to first, so no expense is left without one.
